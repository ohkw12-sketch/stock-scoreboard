# 순환 재검증 — 2026-09-19

## 정정

앞선 7종목 검사는 차트 필터만 검사했다. HPSP의 차트 관찰 통과를 최종 보드 복원으로 볼 수 없으며, 실패형 4종목 제외를 새 규칙의 순증 효과로 볼 수도 없다. 에이스테크·원익IPS·유진테크는 기존 실적 선조건에서 이미 제외된다.

## 매일 같은 조건으로 비교

2026-07-31~09-18의 35거래일, 저장자료 내 일별 2,746~2,762종목을 대상으로 섹터 상태, 실적 선조건, 새 차트 조건, 분산 제한, 최종 Top5를 다시 계산했다. 현재 상장종목 목록으로 과거를 재구성한 것이므로 당시 전체 상장·상장폐지 종목까지 완전히 복원한 검증은 아니다.

- 실제 공시 접수일이 신호일보다 앞선 자료만 사용한다. 같은 날 공시는 시각을 모르면 다음 날부터 사용한다.
- 당시 사용할 수 있는 분기 보고서를 골라 기존 분기 정규화 함수로 4분기를 재계산한다. 나중의 정정본만 있으면 과거 원본을 추정하지 않는다.
- 날짜별 4분기 재무 복원 가능 종목은 2,230~2,317개다. 미복원 종목은 코드별로 기록하고, 0점 실적이나 정상 탈락으로 간주하지 않는다.
- 기존/신규 모두 동일한 실적 선조건과 가격 이력, 최대 5개로 비교한다. 기존 섹터 제한은 4개, 신규는 사용자 지정 2개다.
- 종가에 나온 신호를 같은 종가에 산 것으로 계산하지 않는다. 다음 거래일 시가 진입, 진입일을 1일로 센 5/10/20거래일 종가 청산을 가정한다.
- 왕복 비용은 비교용 가정 0.30%다. 실제 세금·체결 비용이나 슬리피지 추정이 아니다.
- 관찰 후보와 진입 검토 후보를 별도 집계한다. 관찰 후보 수익률은 가상 추적값이다.
- 미도래·거래불가·가격 누락은 null로 둔다. 매일 겹치는 후보는 독립 표본이 아니며 누적 포트폴리오 수익률로 표현하지 않는다.

## 코드 보완

`rotation_walkforward.py`는 가격만 보는 검사를 넘어 위의 날짜별 최종 선정을 재현한다. 원본 공시를 확보한 경우 `--recovered-filings`로 출처가 있는 파싱 레코드를 추가할 수 있다. 이후 정정본과 원본 중 각 신호일까지 공개된 최신 버전을 사용한다. `--resume`은 코드·원자료·설정·기간 식별자가 일치할 때만 허용한다.

`rotation_screener.py` 내부 감사 기록에 실적 수치, 실적 탈락 사유, 실제 노출 여부, 표시 순위, 최종 탈락 단계를 추가했다. 추천 점수와 공개 표는 바꾸지 않는다.

재현: `python rotation_walkforward.py --state <검증 스냅샷을 가진 프로젝트 경로> --out test_output/rotation_walkforward`.

미래 봉 없이 미리 계산한 지표를 잘라 쓰는 방식과 매일 처음부터 계산한 방식이 일치하는지, 공시 공개일 제한, 다음 날 시가 진입, 미도래 처리, 현금 슬롯 계산을 테스트한다. 전체 Python 검사 248개가 통과했다.

현재 목록 편향, 과거 정정 전 자료 일부 미확보, 과거 컨센서스 이력 부족이 남아 있다. 이 결과는 기존보다 넓은 재현 검사이며, 편향 없는 전 시장 실전 백테스트 완료나 향후 성과 보장이 아니다.
