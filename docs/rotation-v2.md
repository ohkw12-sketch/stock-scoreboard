# 순환 v2 구현 기준

## 2026-09-19 사용자 승인 변경: v2.1 조기 관찰

아래의 기존 실적 선조건은 순환 1~3위 진입 검토에 유지한다. 4~5위 관찰에 한해 4분기 실적 완비·공개일 확인·최근 분기 흑자·매출과 영업이익 동반 개선(검증된 전년 동분기 또는 직전 분기 대비)을 충족하면 실적 기준 미달 종목도 후보로 허용한다. 회계기간 말로부터 180일을 넘은 실적은 이 예외에 사용하지 않는다. 해당 후보는 반드시 watchOnly이며 진입으로 자동 승격하지 않는다.

실적 기준 미달 수치와 개선 비교 기준을 핵심근거에 표시한다. 확인한 분기 개선에는 실적 영역 10점을 부여하되, 같은 DART 접수번호의 다른 실적 신호와 중복 가산하지 않는다. 이 신호 자체는 단일봉 과열 예외의 강한 촉매로 인정하지 않는다. 거래량·거래대금·MACD·저항·윗꼬리·과열·섹터/테마 제한은 유지한다. 총 5개 중 관찰 자리는 2개이며, 기존 실적 기준을 통과한 관찰 후보와 동일 점수 순으로 경쟁한다. p1·p2의 선조건은 그대로다.

재현상 한국화장품제조는 2026-08-10, HPSP는 2026-08-19 관찰 4위에 편입됐다. 별도 2026-06-15~06-26의 10거래일 검사에서는 관찰 9건의 가상 5일 평균 비용 차감 수익률이 -7.58%로 나빴다. 관찰 포착 범위를 넓힌 기능이며 수익률 개선이 입증된 전략으로 해석하지 않는다. 계산은 다음 날 시가 진입, 5번째 거래일 종가 청산, 가정 비용 0.30%이며 현재 목록 편향과 과거 공시 버전 부족 등의 재현 한계가 있다. 이 결과를 이유로 특정 종목에 맞춰 기준을 추가 조정하지 않았다.

적용 범위는 순환(p11)이다. p1 진입·p2 가치·성장·보유 평가와 기존 섹터 엔진 가중치는 바꾸지 않는다. 최신 운영본의 4분기 평균 매출 500억원·평균 영업이익률 15% 선조건도 그대로 유지한다. p1은 종전 후보 산출 함수를 계속 사용한다. 건설·바이오/제약은 순환에서 제외하며 반도체 단타 기능을 추가하지 않는다.

## 가격 필수조건

- 종가가 20일 이동평균 이상, MACD(12,26,9)가 Signal 위.
- 거래량: `rolling(3).mean() / shift(3).rolling(14).mean()`. 17개 완성 세션 필요. 1.5배 미만 탈락, 2배 이상 A급.
- 당일 및 최근 3일 평균 거래대금 모두 기존 설정 `minimum_daily_turnover` 이상. 기본 10억원.
- 최근 20개 완료 거래일의 일중 고가 최댓값을 스윙 저항으로 사용한다. 당일 고가는 제외한다. 미래 봉으로 확정하는 피벗은 사용하지 않는다.
- 종가가 저항의 97% 미만이면 탈락. -3%~0%는 관찰만, 종가가 저항보다 높으면 돌파 가점. +10% 초과는 15점 감점·관찰만.
- 20봉 OHLC·거래량·거래대금 정상 이력 필요. 섹터 종료·조기이탈 제외.

## MACD 보존

기존 대화에서 합의했으나 코드에는 없던 노후화 규칙을 구현했다. GC 후 0~3일 100%, 4~7일 90%, 8~12일 75%, 13~20일 55%, 이후 30%. 오래됐다는 이유만으로 탈락시키지 않는다. 2배 거래량과 새로운 종가 돌파가 동시에 발생하면 100%로 재점화한다. 이력 밖 GC는 신규로 추정하지 않고 30%를 적용한다.

## 점수와 근거

- 수급·차트 최대 40: 거래량 1.5배 10점/2배 18점, 종가 돌파 16점/저항 접근 3점, MACD 최대 6점에 노후화 가중치 적용.
- 실적·컨센서스 최대 35: 검증된 흑자 영업이익 성장에 최대 20, 컨센서스 20일 상향에 최대 25. 미래 실적 성장률을 상향률로 대신 쓰지 않는다.
- 신규촉매·업황 최대 25: 기존 검증된 공시 원장에서 신규 유효 호재를 연결한다.
- 동일 `eventId`의 뉴스·실적 등은 가장 큰 기여 한 번만 반영한다. 거래량·돌파·MACD는 상관된 하나의 40점 묶음으로 제한한다. 사건 식별자가 다른 동일 사건은 수집 단계에서 동일 ID로 정규화해야 한다.
- 미확인·미래 공개·출처/사건ID 없는 근거는 0점. 실적은 회계기간 말일이 아니라 DART 접수일을 쓴다. 공개 시각이 없는 당일 자료는 다음 날부터 사용한다. 정정 공시를 과거 원공시 시점으로 소급하지 않는다.
- 실적은 90일, 컨센서스·촉매는 기본 30일 이내. 강한 펀더멘털 촉매 예외는 30일 이내 근거만 인정한다.
- `rotation_evidence_file` JSON 배열로 검증된 사건을 추가 가능: ticker, eventId, source, publishedAt, status=verified, kind(earnings/consensus/catalyst/industry), points, strong. 선택 파일이 지정됐는데 없거나 잘못된 경우 계산 실패를 숨기지 않는다.

## 과열과 관찰

수치가 지정되지 않은 부분은 아래 보수적 초기 기준으로 명시했다. 수익률 최적화나 통계적으로 검증된 확률 기준이 아니다.

- 과열: 당일 종가 +10% 이상, 3일 +15% 초과, 5일 +25% 초과 중 하나.
- 물량 출회 경고: 장중 전일 종가 대비 +10% 이상 상승 후 고가 대비 종가가 5% 이상 밀림, 또는 윗꼬리/전체 범위 ≥45%이고 종가 위치 <60%.
- 물량 출회는 20점 강감점·진입 제외. 비과열이며 나머지 필수조건을 전부 통과한 종목만 관찰 후보로 남긴다.
- 과열은 원칙 탈락. 강한 펀더멘털 촉매 + 거래량 2배 + 종가 돌파 + 종가 위치 ≥80% 및 고가 대비 밀림 ≤3%를 모두 충족해야 15점 감점 후 과열 관찰로 보존한다. 물량 출회 경고가 있으면 이 예외를 허용하지 않는다.
- 후반 섹터는 15점 감점·관찰만.

## 최종 노출

최대 5개. 1~3번 진입 검토 슬롯은 동일 세부테마 1개, 전체 5개 동일 섹터 2개까지. 관찰 전용 종목을 상위 진입 슬롯으로 승격하지 않는다. 진입 후보가 부족하면 순번에 빈자리를 두고 4~5번 관찰 슬롯에 표시하며 3개를 억지로 채우지 않는다.

세부테마는 `rotation_theme_map`의 종목코드→테마 매핑, 가격 자료 `detail_theme`, 섹터 순서로 사용한다. 정보가 없으면 섹터를 같은 테마로 보수적으로 취급한다. 내부 전체 후보는 유지하고 공개 rows만 제한한다. 화면도 5개로 제한한다.

## 재현과 한계

`python -m unittest discover -s tests -p test_rotation_rules.py`로 경계값·중복·미래자료·과열예외·다양성 검증.

`python rotation_replay.py`로 HPSP·한국화장품제조·에스앤에스텍·에이스테크·심텍·원익IPS·유진테크를 재검증한다. Yahoo Finance 수정 OHLCV를 내려받고 Naver 일봉 35개 세션과 비교한다. 자료와 결과는 `test_output/rotation_replay/`에 저장한다.

이 재검증은 종목별 가격 필터 검사다. 당시 전 시장 순위/섹터 상태/실적·촉매 원장을 복원한 포트폴리오 백테스트가 아니다. 거래대금은 종가×거래량 근사치이며 아직 지나지 않은 10/20일 수익률은 null이다. 과거 코드의 유동성 통과와 이전 대화의 2배 규칙은 서로 달랐으므로 따로 비교한다.

실제 데이터는 승인된 전체 새로고침 경로에서 공급한다. 이 변경의 로컬 검증 후보 파일은 최초 검증은 2026-09-08 캐시를 사용했다. 운영 반영 후보는 2026-09-18 검증 스냅샷으로 다시 계산했으며 다른 평가창은 기존 게시 상태를 유지한다.
