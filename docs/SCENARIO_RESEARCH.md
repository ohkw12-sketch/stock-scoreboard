# 시나리오 리서치

기존 평가창 안의 별도 연구 화면이다. 기존 수집기와 검증 스냅샷을 공유하지만 기존 가치·성장·순환 점수를 새 선정에 입력하지 않는다. 기존 p2/p11 순위, p3 보유 수량·평단, 공개 추천 이력은 수정하지 않는다.

## 화면

- `scenarios.html#overview`: 시장 종목 분포, 자료 범위, 세 시나리오 미리보기.
- `#scenarios`: 상승·박스권·하락을 동시에 또는 각각 확인. 기업 조건 통과와 가격 조건 충족을 구분한다.
- `#sectors`: 가격 추세와 외부 이익 전망의 범위를 따로 표시. 연결된 산업통계 원문 표시.
- `#stocks`: 전체 종목 검색·섹터·개선 경로·연구 후보 필터. 노출 제한 밖 종목도 조회 가능.
- `#stock/222800`: 심텍을 포함한 각 종목의 확정 실적, 직접 수집한 분기/연간 전망, 같은 증권사 전후 추정치, 가격 조건, 원문 근거, 판단 변경 조건.
- `#holdings`: 승인된 보유 입력 14개 유지. 기존 검증 근거의 확인 날짜를 유지하며 가격 약세와 실적 악화를 구분.
- `#audit`: 입력 자료 범위, 중복 가능한 보류 사유 수, 기존 가치성장 노출과의 차이, 사례 점검, 미연결 정보.

## 생성·연결

```powershell
python refresh_scenarios.py
python preview_server.py --port 8766
```

미리보기: `http://127.0.0.1:8766/scenarios.html`

`refresh_all.py`의 기존 계산이 완료되면 새 엔진도 동일 원자료로 호출된다. 새 계산 실패는 `test_output/scenario-refresh-status.json`에 기록하고 이전 검증 산출물을 유지한다. 새 기능 실패가 기존 구역의 갱신을 막지 않는다. 별도의 수집 호출이나 LLM 호출은 추가하지 않는다.

입력은 검증 스냅샷의 가격·재무, `forecast_engine/forecast_consensus.json`, `forecast_observations.json`, `guidance.json`, `evidence_snapshot.json`이다. 원본 파일 해시를 계산 전후 비교한다. 기존 비교 대상은 같은 스냅샷의 `data.test.json`이며, 보유 입력은 공개 `data.json.p3`를 기준으로 고정한다.

산출물:

- `test_output/scenario-board.test.json`: 전체 검증 자료. 공개 서버에서 직접 제공하지 않는다.
- `test_output/scenario-public.test.json`: 초기 화면·검색용 요약.
- `test_output/scenario-stocks/<generation>/<prefix>.json`: 52개 분할 상세 자료. 종목을 열 때 해당 파일만 읽는다.
- `test_output/scenario-validation.json`: 입력 불변성·출처·날짜·분산 규칙·보유 입력 검사.
- `cache/scenario_research/`: 내용 식별자로 보존하는 로컬 연구 스냅샷. 실제 추천/배포 성과 원장과 구분한다.

상세 파일을 전부 쓴 다음 요약 파일을 교체한다. 프런트는 상세의 스냅샷 식별자와 엔진 해시를 확인해 다른 세대의 자료를 섞지 않는다. 이전 파일을 삭제하지 않는다.

공개 화면은 검증된 요약을 `scenario-board.json`으로, 해당 세대 상세 폴더와 갱신 상태를 함께 게시한다. 가격 기준일과 생성 시각을 분리해 표시한다. 이번 게시 자료의 가격 기준일은 2026-09-21이며, 더 새로운 자료가 수집된 것으로 표현하지 않는다. 기존 공개 추천은 새 연구 후보로 자동 치환하지 않는다.

## 정보 선택

같은 종목·기간·항목에서 최신 컨센서스와 공식 연결 가이던스 중 더 최근 발표값을 쓴다. 같은 날은 공식 가이던스 우선. 한쪽 항목이 비면 다른 쪽을 사용한다. 60일 초과는 날짜 경고만 표시하고 값 자체를 제거하거나 가중하지 않는다. 증권사 수·자료 나이 가중치는 없다. 기존 수집기가 산출한 증권사 중앙값은 그대로 유지한다.

매출과 영업이익은 각각 실제 값을 제공한 보고서의 날짜·원문을 가진다. 늦게 나온 OP만의 보고서 날짜를 오래된 매출에 붙이지 않는다. 미래 발표일, 불일치 검토, 출처 없는 수치는 제외한다. 직접 수집한 3분기·4분기는 연간 전망과 별도 보존한다. 연간 예상 이익에서 실제 상반기 이익을 뺀 값은 ‘하반기 필요 OP’이며 외부 분기 전망이나 서프라이즈가 아니다.

전망 변경은 같은 증권사·같은 대상 연도·같은 영업이익 항목의 전후값만 비교한다. 같은 날짜의 상충 추출은 제외하며 중복 보고서가 비교 건수를 늘리지 않는다. 공개 집계는 특정 증권사 변경으로 표시하지 않는다. 자료가 없는 종목도 확정 실적 회복 경로로 연구할 수 있다.

## 현재 선정 기준

이 기준은 검증 전 연구 가설이며 성과가 입증된 최적값이 아니다. 화면에 전부 공개한다.

공통: 건설·건축·바이오·제약 제외, 기준일 거래와 60일 이력, 평균 거래대금 10억원, 연간 매출 2,000억원, 실적 또는 전망 개선. 미래 전망 매출이 없으면 확인된 4분기 매출 합계로 규모를 확인한다. 반도체를 포함해 기업 관점은 6~12개월이며 단타 신호가 아니다. 기존 보드의 15% 마진 게이트는 수정하지 않고 새 연구 엔진에서는 업종 공통 필수조건으로 사용하지 않는다.

개선 경로:

1. 실적·전망 동반 개선: 최신 확정 분기 매출·OP가 전년보다 증가하고 OP가 양수이며, 내년 매출이 올해 이상·내년 OP가 올해보다 증가하고 양수.
2. 전망 개선 확인: 위 외부 전망 증가 조건.
3. 실적 회복 확인: 위 실제 개선 조건이며 확인된 내년 OP 감소 전망이 없음.

원자료에서 가장 최신인 확정 분기를 선택하고, 전년 비교 필드의 분기 기준일이 일치할 때만 증가율을 계산한다. 3분기 실제치가 들어오면 개선 판정도 해당 분기로 바뀐다. 상반기 대비 하반기 필요 OP는 별도의 1·2분기 실제 합계로 유지한다.

상승은 **기업 성장 선별을 가격 확인보다 먼저** 한다. 올해·내년 OP 전망 쌍에서 올해 OP 100억원 이상, 내년 OP 증가율 25% 이상이면서 증가액 50억원 이상, 내년 매출 증가율 5% 이상, 최근 실적 급감 없음이 필요하다. 동시에 최근 확정 분기 OP가 전년 대비 25%·30억원 이상 증가하고 매출이 10% 이상 증가했으며 분기 OP마진이 10% 이상이어야 한다. 예상과 확정 실적 한쪽만 강한 종목은 전 종목 탐색에 남기되 상승 첫 후보군에는 넣지 않는다. 금융업은 영업이익의 비교 의미가 달라 이 후보군에서만 제외한다.

올해 상반기 실제 OP와 연간 전망의 차이로 구한 하반기 필요 OP가 상반기 실제 OP의 2배를 넘으면, 직접 수집한 3·4분기 OP 전망의 합이 그 필요액과 20% 이내로 맞아야 첫 후보군에 넣는다. 이 검사는 연간 전망의 큰 하반기 도약을 별도 분기 전망 없이 확정처럼 취급하지 않기 위한 것이다. 분기 전망이 없는 종목의 성장을 부정하는 뜻은 아니다. 이 경계값은 저장된 자료와 사례를 검토한 초기 연구 가설이며 수익률 최적화 결과가 아니다.

성장 기준을 통과한 뒤 종가 > 20일선 > 60일선, 20일 시장 대비 강세, **과거 큰 거래대금 집중 가격대의 거래량 동반 종가 돌파**를 요구한다. 보유한 전체 과거 일봉의 거래대금을 일중 고가·저가 구간에 나눠 가격대별 집중도를 추정한다. 가격대가 형성된 뒤 그 가격대를 넘은 실제 날짜의 거래량이 직전 20일 평균의 1.5배 이상이고 고가권에서 마감했는지 당시까지의 자료로 확인한다. 상승 신호는 이 일이 최근 3일에 일어난 경우다. 최근 3일/그 직전 14일 평균 거래량 ≥1.5배도 유지한다. 2배는 강신호다. 20일 확인 스윙고점은 단기 참고값으로만 남긴다.

박스권: 과거 큰 거래대금 집중 가격대를 거래량 동반 종가로 돌파한 뒤 지지로 바뀐 가격을 **박스 하단**으로 삼는다. 그 돌파 이후 가격 이력에서 하단 지지와 별도의 상단 반락이 각각 두 차례 이상 번갈아 확인돼야 박스 구조로 인정한다. 상단은 그 구간 일중 고가의 90백분위에서 추정하며, 박스 폭은 하단 대비 6~35%여야 한다. 현재 종가가 하단 위 3% 이내이고 전체 박스 폭의 하위 25%에 있어야 후보로 본다. 단순히 매물대 위 5% 이내인 종목은 더는 박스권 조건을 통과하지 않는다. 20일 수익률 ≥−5%, 종가가 60일선의 95% 이상, 당일 상승·일중 상위 40% 마감 조건도 유지한다. 이 수치들은 연구 가설이지 검증된 최적값이 아니다.

상승·박스권 카드의 진입 후보에는 각각의 공통·가격 조건을 모두 통과한 종목만 표시한다. 상승의 예상·확정 실적 동반 성장 후보 중 가격 조건을 기다리는 기업은 **기업 성장 우선후보** 표에 따로 둔다. 가격 조건이 몇 개 남았는지는 선별·순위에 쓰지 않는다. 내년 예상 OP 증가액, 최근 확정 분기 OP 증가액 순으로 비교하고 최대 20개, 동일 섹터 최대 3개를 표시한다. 가격 대기는 진입 통과가 아니다. 표 밖 종목과 각 미충족 사유는 종목 탐색과 개별 상세에서 확인한다. 빈자리는 채우지 않는다.

가격대는 저장된 일봉의 거래대금을 고가·저가 범위에 균등 배분한 **추정**이다. 실제 가격별 체결량, 호가 잔량, 매수·매도 주체를 확보하지 않았으므로 정밀한 매물대 지표나 ‘소화 완료’ 판정으로 부르지 않는다. 조회 가능한 이력 전체를 쓰며 20일·120일 등 고정된 구간만으로 가격대를 선정하지 않는다. 과거 돌파 검사는 각 돌파일 직전까지의 자료로 가격대를 다시 만들어 사후 자료 혼입을 막는다. 이전 20일 스윙고점과 이동평균선은 각각 단기 참고선과 추세 확인용으로 분리한다.

하락: 20일 상대성과 ≥0, 60일선 유지, 60일 고점 대비 낙폭 15% 이내, 확정 이익·전망 감소 점검. 충족해도 ‘방어 관찰’이며 자동 매수·비중 계산이 아니다.

급등 후 긴 윗꼬리·종가 밀림은 공통 제외. 이격 과다도 진입 조건 충족으로 표시하지 않는다. 다른 모든 공통 조건과 실적·전망 동반 개선, 거래량 2배, 종가 돌파, 일중 상위 20% 마감이 함께 충족된 경우에만 과열 관찰로 유지한다.

상승 진입 후보는 조건 충족 → 비과열 → 내년 예상 OP 증가액 → 최근 확정 분기 OP 증가액 순으로 정렬한다. 박스권·하락 시나리오의 기존 정렬은 유지한다. 합산 점수, 기사/수주 건수, 작은 이익 기저의 성장률을 순위 가점으로 쓰지 않는다. 진입 후보는 시나리오마다 최대 5개 섹터·섹터당 3개이며 빈칸을 억지로 채우지 않는다. 모든 회사는 종목 탐색에서 이유와 함께 확인 가능하다.

## 실제로 확인한 범위와 한계

2026-09-21 저장 가격 기준: 요청 2,762종목, 기준일 가격 2,746, 확정 4개 분기 2,318, 외부 전망 549, 올해·내년 OP 쌍 346, 분기 OP 전망 343, 동일 증권사 전후 추정치 70. 새로 외부 정보를 수집한 결과가 아니다. 가격 누락 16종목은 이름과 함께 노출한다.
